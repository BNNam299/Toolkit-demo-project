# Hợp đồng API / tích hợp

> File này do **Dev** viết. PO và AI không sửa nội dung ở đây.
> Điền `version`, `date` và đổi `status` khi nộp.

## Nội dung tối thiểu cần có

- Bảng endpoint: method, input, output, thời gian phản hồi kỳ vọng, FR liên quan
- **Mã lỗi và hành vi app tương ứng** — mỗi mã lỗi map tới một trạng thái UI
- Trường hợp độ tin cậy thấp: ngưỡng nào coi là không đủ tin, app xử lý thế nào
- Rate limit, quota, chi phí mỗi lượt gọi, hành vi khi vượt quota
- Phiên bản API và chính sách thay đổi
