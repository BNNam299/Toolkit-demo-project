# Ideation — How Might We, choosing between options

> Source: bnnam-appdev-toolkit/design-toolkit/2.0.0/knowledge/ideation.md (Notion) @ 3c0e291 — translated, complete

A thinking lens for any step where you must choose between several options (layouts, flows, patterns). Most Design Thinking work
happens before the PRD; a few tools are useful when choosing a design option.

## 1. Design Thinking — the frame
- User-centred; **non-linear and iterative**, stages 1–5 need not run in order; **always tied to a concrete context**.
- Five stages: Empathize · Define · Ideate · Prototype · Test.
- **Insight** = a hidden truth, hard to spot, that drives behaviour / decisions.

## 2. Empathize — tools
- T-T-M (Truth–Tension–Motivation) · 3C · empathy map · journey map.
- **5 Whys** — ask "why" repeatedly down to the root cause; one effect with several causes → dig each branch.
- **Kipling** (What–Where–When–Who–How; stick to the problem's keywords) — 5 Whys first, then Kipling for each cause.
- **Beginner's mindset** — put yourself in the shoes of a first-time user to predict the experience. Example, the Canon camera dial:
  **basic functions → understandable icons; advanced functions that cannot be drawn as icons → abbreviations** (experienced users
  recognise them fast). → matches the UI rule "push an unfamiliar feature straight out where it can be seen".

## 3. Define — tools
- **JTBD** — customers do not buy a product, they **hire** it to do a job (a box cutter → cut a big sheet into many small ones).
- Lotus Blossom · Fishbone (head = the cause from 5 Whys, bones = Kipling factors) · empathy map (real people).
- **POV = user + need + insight.**
- **How Might We** ("How might we…" — one problem opens many solution directions).
- User story · affinity diagram.

## 4. Ideate — tools
- **Brainstorm** — **do:** respect other ideas, the more the better without worrying about feasibility yet, cluster similar ideas ·
  **don't:** shoot ideas down, hold back an idea for fear it is not feasible, throw ideas out with no theme.
- Storytelling / journey · Lotus.
- **Connecting the dots** — list Methods / Objects / Attributes / Other properties, then connect any of them.
- **Idea selection — three angles:** can we build it (feasibility) · will customers want it (desirability) · does it pay
  (viability).
- Golden Circle (Why → How → What).

## 5. How this skill uses it
- **How Might We** is the official way to **reframe the question** when the work goes in circles.
- The **three selection angles** are used when choosing between layout / flow options — say for each option how it scores on
  feasibility, desirability and viability, and recommend one (the three pillars in depth: `foundations.md` §5).
